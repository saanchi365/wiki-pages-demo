# 📚 Shelfie – library app (demo)

> **Demo project with made-up content.** It exists only to try out GitHub **Wikis** and **GitHub Pages**. Shelfie is not a real product.

Shelfie is a small app for a town library. Members can **search** for books, **borrow** them, **renew** loans and **return** books. Librarians manage the catalogue.
