# Journey map – borrowing a book

*Made-up content for the Shelfie demo.*

| | 1. Search | 2. Check availability | 3. Reserve | 4. Pick up | 5. Return |
|---|---|---|---|---|---|
| **Doing** | Types a title or author | Looks at copies and branches | Taps "Reserve" | Shows member card at the desk | Drops the book in the return box |
| **Feeling** | Hopeful | Anxious: is it there? | Relieved | Happy | Done, maybe forgetful |
| **Needs** | Forgiving search (typos) | Clear "available today" label | Confirmation and pick-up time | Fast desk check-out | A reminder before the due date |
| **Opportunities** | Suggest spellings | Show the nearest branch with a copy | Hold the book for 2 days | Self check-out machine | Reminder 2 days before due |
