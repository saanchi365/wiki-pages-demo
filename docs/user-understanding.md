# User understanding

*Made-up content for the Shelfie demo.*

## Members
- Age 10 to 80. Many are students and retired people.
- Mostly use a **phone**, sometimes the library's computers.
- Want to find a book **quickly** and know if it's available **today**.

## Librarians
- Use a **desktop** computer all day.
- Add new books, fix catalogue mistakes, and help members at the desk.

## Needs
| Member needs | Librarian needs |
|---|---|
| See if a book is available before travelling | Add many books quickly |
| Get a reminder before a book is due | See overdue books at a glance |
| Renew without visiting | Fewer questions at the desk |

## Pain points today
- Members travel to the library and find the book already borrowed.
- Paper reminders arrive late.
