# Use cases

*Made-up content for the Shelfie demo.*

1. **Search for a book**: a member finds a book by title, author or topic.
2. **Borrow a book**: a member reserves an available copy and picks it up.
3. **Renew a loan**: a member extends the due date without visiting.
4. **Return a book**: a member returns a book, and the loan closes.
5. **Add a book** (librarian): a librarian adds a new book to the catalogue.
